# Journal 0.1.3

A published release with opt-in coordinated runs on macOS. The maintainer will perform authenticated team validation after download; that acceptance is not yet complete. Windows orchestration remains deferred.

## Download and test

Use `Journal-0.1.3-arm64.dmg` on an Apple Silicon Mac, or the ZIP of the same app. The tag pipeline signs with Developer ID, notarizes, audits package contents, installs from the DMG and smoke-tests the app with fixture providers. Check the completed release workflow before treating signing or notarization as verified.

Open Settings and enable **Coordinated runs** to try the experiment. Choose **Coordinate** in a named Git branch, use a disposable project, and follow the [native validation worksheet](../ORCHESTRATION-VALIDATION.md#local-native-session-worksheet). Existing ordinary terminal sessions remain available.

## Changes

- Coordinators, dependent tasks and isolated workers, with shared capacity and durable launch queues.
- Team views for plans, workers, results, messages, capacity, policy and run history.
- Immutable result identities, exact-result reviews, conflict/recheck workflows, guarded integration and explicit memory review.
- macOS isolated result checks with filesystem/network restrictions and bounded execution.
- Recovery through window/runtime process loss, durable MCP request replay, and conservative handling of unknown outcomes.
- Leftover-process cleanup now waits for observed exit before releasing a worker folder; a signal alone no longer clears the writer guard.

## Validation and remaining gates

The implementation passed 886 unit/integration tests (2 skipped), 162 desktop tests (1 skipped), type checking, renderer build, package audit and packaged fixture smoke locally. CI verifies the tagged version again. Automated provider behavior uses isolated fixture CLIs, never real provider logins or requests.

Automatic PTY delivery, Stop-hook continuation and live-folder mutation remain disabled on production adapters pending provider/version qualification. Pull messaging and explicit stopped-worker integration are available. Authenticated MCP permission/resume/conflict trials and the usefulness trial remain manual. Higher concurrency stays capped at four pending calibration. Missing dependencies in immutable checks are a test failure; Journal does not borrow mutable dependencies or install over the network.

A crash before process inventory or inside an uncheckpointed Git mutation can require inspection. Unknown writers and uncertain delivery are held, never inferred safe or replayed automatically. This release does not claim completion of M10b native acceptance.

The user explicitly authorized publishing v0.1.3 on 7 October 2026. The workflow first creates a draft; it is published after artifact verification. Provider capability limitations above remain explicit and are not treated as successful native validation.
